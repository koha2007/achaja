## 0. 전제 (확정된 결정)

- 유료 판매는 **보류**한다. 무료 도구로 방문을 늘리고, 회원가입으로 사람을 모은다.
- 회원 전용 **서류 판독 베타**로 유료 수요를 검증하고, 출시 기준을 넘으면 유료로 전환한다.
- 사람은 도구 때문에 가입하지 않는다. **가입해야만 얻는 것**이 있어야 가입한다. 이 설계의 중심은 그것이다.
- 자동 콘텐츠는 원문 재작성이 아니라 **구조화 + ACHAJA 관점**으로 만든다(구글 스팸 정책 대응).

## 1. 정보 구조 (IA) — 사용자 상황 기준 4축 + 내 차

지금 메뉴(홈·뉴스·블로그·이력조회·리콜·마이)는 **기능 이름** 기준이다. 개편 후에는 사용자의 **상황** 기준으로 묶는다.

| 메뉴 | 사용자 상황 | 담는 것 |
|---|---|---|
| **살 때** | 중고차를 보고 있다 | 매물 체크(기존 이력조회 개편), 서류 판독 베타, 리콜 조회, 구매 가이드 |
| **아플 때** | 차에 이상이 생겼다 | 증상 진단, 경고등 사전, 정비 가이드 |
| **관리** | 내 차를 잘 굴리고 싶다 | 오늘의 유가, 날씨별 관리 팁, 계절·나라별 점검 데이터, 정비 주기 |
| **소식** | 차 이야기를 보고 싶다 | **신차(출시 예정 캘린더·모델 페이지·실구매가 계산기)**, 주간 브리핑(뉴스) |
| **내 차** (회원) | — | 내 차 등록, 알림, 저장한 매물, 판독 내역 |

- 블로그 44편은 사라지지 않고 각 축의 **가이드**로 재분류한다. URL은 유지하고 메뉴에서만 재배치한다(검색 순위 보존).
- 모바일 하단 탭: 살 때 · 아플 때 · 홈 · 관리 · 내 차 (소식은 홈과 관리에서 노출)
- 데스크톱 상단: 로고 · 살 때 · 아플 때 · 관리 · 소식 · [내 차 / 로그인]

## 2. 무료 도구 상세

### A. 매물 체크 (살 때) — 기존 `/history` 개편
- **입력**: 차대번호(VIN) 또는 차종·연식 / 호가 / 주행거리 / 지역 / (선택) 자동차365 평균가
- **자동 조회(우리 API)**: VIN 해독, 리콜 매칭, 성능점검 통계
- **판정(AI)**: 적정가 판정(사용자가 입력한 자동차365 평균가를 주행거리·연식으로 보정), 미끼 매물 경고, 이 차종 주의점 3개
- **외부 원클릭**: 자동차365 평균가·실매물 조회, 카히스토리 사고이력(770원), 리콜센터
- **가입 유도**: "이 매물 저장하고 비교하기", "서류까지 판독받기(회원 무료)"
- 판정은 신호등 배지(적정 / 주의 / 위험)로 한눈에 보여 준다.

### B. 서류 판독 베타 (살 때) — **회원 전용, 월 2회**
- 성능상태점검기록부 + 카히스토리 결과 캡처 업로드 → 위험 신호 판독
  - 골격/외판 교환·판금 의미, 침수 흔적, 기록부↔보험이력 불일치, 주행거리 이상
- **개인정보**: 이미지는 서버에 저장하지 않는다. 판독 요청에만 쓰고 즉시 폐기한다. 판독 결과 텍스트만 회원 계정에 저장한다.
- **고지**: "참고용 판독이며 현장 점검·전문가 진단을 대신하지 않습니다."
- 판독마다 "도움이 됐나요? / 유료여도 쓰겠나요?" 두 질문 → 유료 출시 판단 데이터
- 회원 한도로 AI 비용을 통제한다.

### C. 증상 진단 (아플 때) — 신규
- **입력**: 증상 선택(소리·진동·경고등·냄새·누유·시동) + 자유 입력 + 차종·주행거리
- **출력**
  - 예상 원인 TOP 3
  - **긴급도 신호등**: 바로 정차 / 이번 주 안에 정비소 / 다음 점검 때
  - 예상 수리비 범위 + "정비소에서 이렇게 말하세요" 문장
  - 해당 차종 리콜이 있으면 연결("무상 수리 대상일 수 있습니다")
- 수리비는 정확도가 신뢰를 좌우한다. 처음에는 항목별 **자체 범위표**(부품·공임 대략값)를 만들고, AI가 임의로 숫자를 지어내지 않게 표 안에서만 답하게 한다.
- 비회원도 쓸 수 있지만 하루 사용 횟수를 제한한다. 회원은 진단 기록을 저장한다.

### D. 내 차 등록 & 알림 (내 차) — **핵심 가입 이유**
- **등록**: 차종·연식·연료·주행거리·최근 정비일. 차량번호는 받지 않는다(개인정보 최소화).
- **알림 (이메일)**
  - 내 차종 신규 리콜
  - 자동차 정기검사 시기
  - 엔진오일·타이어·배터리 등 소모품 교체 시기(주행거리 기준 예측)
  - 계절 알림(한파 전 배터리, 장마 전 와이퍼 등)
- 월 1회 "내 차 리포트" 메일로 다시 방문하게 만든다.

### E. 매일 바뀌는 정보 (관리 / 홈)
- **오늘의 유가**: 오피넷 API, 전국·시도 평균, 전일 대비 ▲▼
- **오늘의 차 관리 팁**: 기상청 API 기반(한파·폭우·폭염·미세먼지)
- 둘 다 홈 상단에 둔다. 매일 바뀌어야 매일 들어온다.

### F. 자동 콘텐츠 (소식 / 관리) — 주 2~3회
| 종류 | 주기 | 구성 |
|---|---|---|
| 주간 브리핑 | 주 2회 (월·목) | 이슈 5개 + 각 이슈의 "중고차 사는 사람/차 가진 사람에게 의미" 한 줄 + 원문 링크 |
| 신차 소개 | 주 1회 이상 | 고정 템플릿: 가격대, 제원, 연비, 핵심 기능, 경쟁차 비교표, 출시일 |
| 점검 데이터 | 주 1회 | 계절·날씨·나라별 점검 글. 각 글에 ACHAJA 데이터(리콜·유가·통계) 1개 이상 필수 |

### G. 신차 자동 소개 (소식) — **회원 모집의 핵심 축** (2026-10-15 추가)

사용자 판단: 신차는 매일 나오지 않지만, 나올 때마다 검색이 몰리고 회원 모집에 큰 비중을 차지한다.

#### 글로벌 벤치마크 — 신차 콘텐츠로 성공한 곳
| 서비스 | 무엇으로 사람을 모으나 | 수익 | ACHAJA 적용 |
|---|---|---|---|
| **CarDekho** (인도) | **출시 예정 신차 캘린더**(월별·가격대별·차종별), 예상 가격·출시일, **"출시되면 알림"** 버튼. 월 약 6천만 명 중 **유입의 약 90%가 검색** | 딜러 리드·금융·보험 연결 | 출시 예정 캘린더 + 출시 알림 = 회원가입 이유 |
| **CarWale** (인도) | 브랜드별 출시 예정 신차, 예상 출시일·가격 | 리드 | 같은 패턴이 업계 표준임을 확인 |
| **carwow** (영국) | 신차 리뷰 영상·비교, 원하는 사양을 고르면 딜러 견적이 옴. 월 약 670만 방문 | 딜러 과금(역경매) | 신차 페이지 끝에 "견적·실구매가" 도구 연결 |
| **Car and Driver / Edmunds** (미국) | 모델별 고정 페이지(가격·트림·제원·경쟁차), 검색 유입 상위권 | 광고·리드 | 모델 1대 = 1페이지 고정, 계속 갱신 |
| 국내: 다나와 자동차 | 신차 견적, 렌트·리스 가격 비교, 자동차 백과 | 리드 | 국내 사용자는 **"가격표·실구매가·출시일·OO vs XX"**를 가장 많이 찾는다 |

**결론**: 신차로 사람을 모으는 곳은 공통적으로 ① 출시 예정 캘린더 ② 모델별 고정 페이지 ③ 출시 알림 ④ 가격 계산 도구를 갖고 있다. 한 편의 기사로 끝내지 않는다.

#### 자동 게시 가능 여부 — **가능 (단, 사람 승인 후 게시)**
| 단계 | 방법 | 데이터 출처 |
|---|---|---|
| 감지 | 매일 새벽 Cron이 신차 신호를 모은다 | 네이버 뉴스 API("출시·사전계약·공개" 키워드, 이미 연동됨) / 제조사 뉴스룸·보도자료 목록 / **한국에너지공단 자동차 표시연비 API**(신차는 판매 전 연비 신고 → 출시 전 감지 신호, 이용 제한 없음) |
| 사실 수집 | 가격·트림·제원·연비·출시일 | 제조사 보도자료·가격표, 표시연비 API |
| 초안 | Claude가 **고정 템플릿**으로 작성: 한 줄 요약 / 가격·트림 / 성능(파워트레인·연비) / 디자인 이야기 / 새 기능 / 경쟁차 비교표 / 이런 사람에게 맞음 / 출시일 | 사실(가격·제원)은 저작권 대상이 아니다. 문장은 ACHAJA가 새로 쓴다(보도자료 복사 금지) |
| 사진 | 6장 사진 규칙 적용 (6-5 사진 이용 허가 참고) | |
| 검수 | 운영자 승인 메일 → 게시 | 처음 3개월 필수 |
| 갱신 | 같은 모델 페이지를 사전계약 → 출시 → 가격 변경 시 **업데이트**(새 글 X) | |

#### 신차 영역 구성
1. **출시 예정 캘린더** — 이번 달·다음 달 출시 예정, 차종·가격대 필터, "출시되면 알림"(회원)
2. **모델 페이지** — 모델 1대 1페이지, 출시 단계(공개 → 사전계약 → 출시)에 따라 자동 갱신
3. **신차 실구매가 계산기** (무료 도구, 신규) — 차량가 + 취득세 + 공채 + 탁송 + 번호판 → 실제 내는 돈, 할부 월 납입금. 국내 검색 수요("OO 실구매가")가 크고 모델 페이지마다 붙일 수 있다
4. **경쟁차 비교** — "OO vs XX" 비교 페이지(검색 유입)
5. **주간 신차 브리핑 메일** — 회원 뉴스레터에 포함

## 3. 회원 설계

### 로그인 방식 — **확정: 카카오 + 이메일 동시 오픈 (국내 우선)**
| 방식 | 역할 | 준비 |
|---|---|---|
| **카카오 로그인** (주 버튼) | 국내 가입 전환율 최상. 버튼 하나로 가입 | 카카오 디벨로퍼스 앱 등록 → **비즈 앱 전환**(사업자등록번호 등록) 후 이메일을 필수 동의항목으로 설정. 비즈 앱 심사 지연·반려 사례가 있으므로 **가장 먼저 신청** |
| **이메일 매직링크** (보조) | 카카오 미사용자·PC 사용자. 비밀번호 없음 | Brevo 재사용 |
| 네이버 로그인 | 후순위 | — |

- 알림 채널: 1차는 **이메일**(무료). 회원이 늘면 **카카오 알림톡**(건당 약 5~13원, 발송량·대행사별 상이, VAT 별도) 추가 검토 — 국내 사용자는 이메일보다 카톡을 훨씬 많이 확인한다.

### 저장소
- 현재 Worker에는 KV만 있다. 회원·차량·사용 횟수는 관계형 데이터이므로 **Cloudflare D1** 추가를 제안한다.
- 테이블 초안: `users`(이메일, 가입일, 수신동의) / `cars`(회원별 차량) / `usage`(판독·진단 사용 횟수) / `saved_listings` / `waitlist`(유료 대기자)

### 가입 유도 지점 (기본 도구는 막지 않는다)
- 매물 체크 결과 하단: "저장하고 비교하기"
- 서류 판독 버튼: "회원은 월 2회 무료"
- 리콜 조회 결과: "내 차 리콜 생기면 알려드릴까요?"
- 증상 진단 결과: "진단 기록 저장 + 정비 시기 알림"
- 콘텐츠 하단: "주간 브리핑 메일로 받기"

### 필수 정비
- 개인정보처리방침 개정(수집 항목·보관 기간·탈퇴 시 즉시 삭제), 마케팅 수신 동의 분리, 탈퇴 기능
- `/my` 페이지의 "준비 중" 문구 교체

## 4. 유료 전환 기준 (게이트) — **확정 (Claude 판단, 2026-10-15)**

처음 제안(회원 1,000 / 판독 월 300건)은 작은 사이트에 비해 높아 출시가 계속 미뤄질 위험이 있다. **"규모"보다 "지불 의사 신호"를 우선**하도록 조정했다.

| 구분 | 지표 | 기준 | 이유 |
|---|---|---|---|
| 필수 | 판독 후 설문 응답 수 | **100건 이상** | 이보다 적으면 비율이 우연일 수 있다(오차 약 ±10%p) |
| 필수 | "유료여도 쓰겠다" 비율 | **30% 이상** | 실제 결제는 응답보다 훨씬 낮다. 30% 미만이면 유료 출시해도 매출이 거의 없다 |
| 필수 | "판독이 정확했다" 비율 | **80% 이상** | 정확하지 않은 것을 팔면 환불과 신뢰 하락으로 끝난다 |
| 규모 (둘 중 하나) | 유료 출시 대기자 | **100명** | 출시 첫 달 매출의 근거 |
| | 누적 회원 | **500명** | |

- 필수 3개 + 규모 1개를 넘으면 서류 판독부터 유료 전환.
- **기한**: 2027-04 (회원 기능 오픈 후 약 6개월)까지 못 넘으면 계속 기다리지 않고 재검토한다 — 판독 기능 개선 / 가격 / 다른 유료 아이템.

## 5. 가격 설계

### 5-1. 향후 유료 상품 (게이트 통과 후)
중고차 구매는 몇 년에 한 번 하는 일이다. **월 구독은 구매 행동과 맞지 않는다** → 기존 구독 3종(4,900·9,900·29,900원)은 폐지하고 **건별 + 묶음**으로 단순화한다.

| 상품 | 가격(안) | 내용 |
|---|---|---|
| 회원 무료 | 0원 | 서류 판독 월 1회(전환 후 2회 → 1회로 조정) |
| 구매 판정 리포트 1건 | **4,900원** | 서류 판독 + 적정가·미끼 매물 + 협상 금액·스크립트 + 현장 점검표 PDF |
| 비교 3건 | **9,900원** | 매물 2~3대를 놓고 비교할 때(건당 3,300원) |
| 만족 보증 | — | 판독 결과에 불만족 시 7일 내 환불 |

- 1,900원은 가치를 싸 보이게 만들고 결제 수수료 비중이 크다. 4,900원은 Carfax 대비 약 1/12로 여전히 저렴하다.
- 가격은 베타 응답("얼마면 쓰겠나요")으로 출시 전에 다시 검증한다.

### 5-1-2. 마진율 비교 (2026-10-15 계산)

가정 (실측 전 추정치):
- 판독 1건 API 비용: 사진 2장 + 판정 1회 기준 Opus 5.5 약 270원, Sonnet 5.5 약 135원 → 여유 1.5배 적용 **Opus 405원 / Sonnet 202원** (환율 1,400원/$)
- 판매가는 부가세 포함 → 공급가 = 판매가 ÷ 1.1
- PG 수수료 3.3% (토스페이먼츠 실제 요율 **확인 필요**, 영세·중소 우대 적용 시 더 낮아질 수 있음)
- 환불 충당 5% (만족 보증 대비)

| 상품 | 공급가 | 건당 이익 (Opus) | 마진 (Opus) | 건당 이익 (Sonnet) | 마진 (Sonnet) |
|---|---|---|---|---|---|
| 기존 단건 1,900원 | 1,727 | 1,173원 | 68% | 1,376원 | 80% |
| 기존 묶음 5건 7,900원 | 7,182 | 4,537원 | 63% | 5,552원 | 77% |
| **신규 단건 4,900원** | 4,455 | **3,665원** | **82%** | 3,868원 | 87% |
| **신규 비교 3건 9,900원** | 9,000 | **7,008원** | **78%** | 7,617원 | 85% |

**판단**
- 마진율 차이보다 **건당 이익 차이**가 결정적이다. 4,900원은 1,900원보다 건당 약 3.1배를 남긴다. 같은 이익을 내려면 1,900원은 **3배 많은 사람이 결제**해야 한다.
- 고정비(아래 5-2, 월 약 15만 원 가정)를 넘는 손익분기: 4,900원은 **월 약 41건**, 1,900원은 **월 약 128건**.
- API 비용은 마진을 크게 흔들지 않는다. 진짜 비용 위험은 **무료 베타 판독**(회원 무료분)이다 — 월 200건이면 Opus 기준 약 8만 원. 회원 한도로 통제한다.
- 결론: **4,900원 / 비교 3건 9,900원 유지 권장.** 묶음 5건은 중고차 구매 행동(2~3대 비교)과 맞지 않아 폐지.
- 판독 정확도를 Opus 5.5 / Sonnet 5.5로 각각 테스트한 뒤 모델을 정한다(정확도가 같으면 Sonnet으로 비용 절반).

## 6. 사진 이미지 설계

### 6-1. 원칙
- 무료 도구·콘텐츠에 **새로 올라가는 건마다 대표 사진 1장**(필요 시 본문 1~2장).
- 주제: 자동차, 도로, 풍경. 계절·날씨·글 주제에 맞춘다.
- **번호판·사람 얼굴이 식별되는 사진은 쓰지 않는다**(개인정보·초상권).
- 모든 사진에 출처 캡션(사진가 · 출처 링크)과 대체 텍스트(alt)를 단다.
- **뉴스 기사 사진은 절대 쓰지 않는다**(언론사 저작권).

### 6-2. 사진 소스 — 무료 / 유료 비교

| 소스 | 비용 | 조건 | 용도 |
|---|---|---|---|
| **Unsplash API** | 무료 | 사진가·Unsplash 출처 표기 필수, Unsplash 이미지 주소를 그대로 써야 함(재호스팅 불가), 사용 시 다운로드 기록 API 호출 필수. 데모 시간당 50회 → 심사 후 상향 | 풍경·도로·감성 사진 |
| **Pexels API** | 무료 | Pexels 링크·사진가 표기, 시간당 200회·월 20,000회 (무료로 상향 신청 가능) | 도로·정비·도시 사진 |
| Pixabay | 무료 | 약관 미확인 → 채택 전 확인 | 보조 |
| **AI 생성** (Cloudflare Workers AI, flux-1-schnell) | 일 10,000 뉴런 무료 할당 안에서 수백 장/일 수준, 초과 시 1천 뉴런당 $0.011 (장당 1원 미만) | **실제 차종 묘사 금지**(로고·디자인 왜곡). 풍경·도로·계절 분위기 컷만. "AI 생성 이미지" 표기 | 계절·날씨 팁, 사진이 부족한 주제 |
| 유료 스톡 (Shutterstock / Adobe Stock) | 약 월 $29 / 10장 (연간 약정 기준, 업체 사이트에서 재확인) | 표준 라이선스 | 고품질 대표 이미지가 필요할 때 |
| 제조사 보도 사진 | 무료지만 **허가 필요** | 현대차 홈페이지 약관: 사전 서면 동의 없는 복제·게시 금지, 상업적 이용 불가 | 신차 소개 — **홍보팀 허가 전에는 사용 불가** |

### 6-3. 추천안 — 기본 0원
1. **큐레이션 사진 라이브러리**: Unsplash·Pexels에서 처음에 200장 정도를 사람이 직접 골라 태그(계절·날씨·도로·도시·야간·정비·고속도로·해안 등)와 함께 목록으로 만든다. 품질을 사람이 통제한다.
2. 자동 게시 때 글 태그로 라이브러리에서 고르고, **최근 30건에 쓴 사진은 제외**해 반복을 막는다.
3. 맞는 사진이 없으면 AI 생성으로 보충한다(풍경·분위기만).
4. **신차 소개**는 실차 사진 없이 시작한다: 도로 사진 + 제원 카드 디자인 + "제조사 공식 사진 보기" 링크. 현대·기아·제네시스 등 홍보팀에 언론·정보 사이트 이용 허가를 요청하고, 허가받은 제조사부터 실차 사진을 쓴다.
5. 매달 사진 품질이 부족하면 그때 유료 스톡(월 약 $29)을 추가한다.

### 6-5. 제조사 사진 이용 허가 — 무료인가 / 규제 / 자격 (2026-10-15 조사)

| 질문 | 답 |
|---|---|
| **무료인가?** | 허가만 받으면 **사용료는 무료**인 것이 일반적이다. 제조사는 신차가 많이 노출되기를 원한다. 다만 허가 없이 쓰면 저작권 침해다. |
| **규제(법)는?** | 사진은 저작권법 보호 대상. 보도자료 사진이라도 **"공개된 것 = 마음대로 써도 됨"이 아니다.** 현대차 홈페이지 약관: 사전 서면 동의 없는 복제·게시 금지, 상업적 이용 불가. 제네시스: 사용 전 저작권자 사전 허락 + 출처 표시. 상표(로고)는 상품 소개 목적의 정확한 사용은 일반적으로 허용되지만, 제휴·공식으로 오인되게 쓰면 안 된다. |
| **자격 조건은?** | 공식 기준은 공개돼 있지 않다. 국내 제조사 언론 자료실은 보통 **등록 언론사·기자** 대상이다. ACHAJA는 언론사가 아니므로 **"자동차 정보 사이트로서 신차 소개 목적 사용"을 홍보팀에 개별 요청**해야 한다. 사업자등록증·사이트 소개·사용 범위(신차 소개 페이지, 출처 표기, 수정 없음)를 함께 보내면 승인 가능성이 올라간다. |
| **예외 가능성** | 위키 등 2차 자료에 따르면 **현대차그룹 뉴스룸(HMG 저널)이 직접 제작한 기사·사진은 누구나 사용 가능(2018-05-04 이후, 워터마크 사진 제외)**이라고 정리돼 있다. 공식 원문은 미확인 → **사용 전 뉴스룸 공식 이용 안내를 확인**. 사실이면 현대·기아·제네시스(국내 판매 대부분) 사진 문제가 크게 해결된다. |

**진행 순서**
1. HMG 뉴스룸 공식 이용 안내 확인 (가장 큰 효과)
2. 미확인·불허 제조사는 홍보팀에 이메일 요청 (요청서 초안은 Claude가 작성 가능)
3. 허가 전에는 6-3의 방식(도로·풍경 사진 + 제원 카드 + 공식 사진 링크)으로 게시
4. 허가 내용(제조사·범위·날짜·담당자)을 문서로 보관

### 6-4. 기술 처리
- Unsplash는 원본 주소 사용 조건이므로 크기 파라미터로 최적화된 주소를 쓴다. Pexels·AI 이미지는 WebP로 변환해 저장한다(R2 또는 정적 자산).
- 대표 이미지는 16:9, 목록 썸네일은 4:3. `loading="lazy"`, 첫 화면 이미지만 우선 로딩.

## 7. 디자인 대개편

### 7-1. 현재 진단
- 사진이 한 장도 없다(홈·블로그 모두 `<img>` 0개). 텍스트와 아이콘뿐이라 "정보 사이트"로 보이고 머물 이유가 약하다.
- 글꼴 Manrope·Inter는 **한글을 지원하지 않는다** → 한글은 기기 기본 글꼴로 표시돼 기기마다 모양이 다르다.
- Tailwind를 CDN으로 실행 중(브라우저에서 매번 CSS 생성) → 느리고 운영용으로 권장되지 않는다.
- 색상 변수·헤더·푸터가 페이지마다 복사돼 있다 → 한 곳을 고치면 수십 개 파일을 고쳐야 한다.
- 남색 기본색(`--c-primary` 0 49 120)과 다크 모드는 완성도가 있으므로 **유지**한다.

### 7-2. 방향 — "도로 위의 믿을 만한 정비 친구"
- **사진 중심 매거진 + 도구 대시보드**의 혼합. 콘텐츠는 큰 사진으로 들어오게, 도구는 판정이 한눈에 보이게.
- 판정·긴급도는 **신호등 3색**으로 사이트 전체에서 같은 의미로 쓴다.

### 7-3. 디자인 시스템
| 요소 | 결정 |
|---|---|
| 기본색 | 남색 유지 (신뢰) |
| 의미색 | 안전/적정 = 초록, 주의 = 주황, 위험 = 빨강 (판정·긴급도·유가 등락 전용) |
| 글꼴 | **Pretendard** (한글·영문·숫자 통일, 무료) — 숫자는 고정폭 숫자(tabular)로 유가·가격 정렬 |
| 모서리·그림자 | 카드 12px 라운드, 그림자는 아주 약하게 |
| 아이콘 | Material Symbols 유지 |
| 다크 모드 | 유지. 사진 위 텍스트는 어두운 그라데이션 오버레이로 양쪽 모드 대응 |

### 7-4. 핵심 컴포넌트
1. **사진 카드** — 16:9 사진 + 카테고리 칩 + 제목 + 출처 캡션
2. **도구 카드** — 아이콘 + 한 줄 설명 + "바로 쓰기"
3. **판정 배지** — 신호등 색 + 한 단어(적정 / 주의 / 위험)
4. **오늘의 유가 위젯** — 휘발유·경유·LPG, 전일 대비 ▲▼
5. **오늘의 관리 팁 배너** — 날씨 사진 배경 + 팁 한 줄
6. **가입 유도 배너** — 혜택 한 줄 + 이메일 입력 한 칸
7. **모바일 하단 탭바**

### 7-7. 기술 기반 정비 (디자인 개편과 함께)
- Tailwind CDN → **빌드 시 CSS 생성**(Tailwind CLI)으로 공용 CSS 파일 1개.
- 헤더·푸터·색상 변수를 **공용 조각**으로 만들고 빌드 스크립트가 각 페이지에 끼워 넣는다(`scripts/` 기존 생성기 방식 확장).
- 자동 콘텐츠 페이지는 Worker가 KV/D1 데이터로 HTML을 만들어 응답한다(검색엔진이 읽을 수 있게 서버에서 렌더링).

## 8. 자동 게시 파이프라인 (사진 포함)

```
Cron (월·수·목·금 새벽) 
 → 수집: 네이버 뉴스 API / 리콜 DB 신규 / 오피넷 / 기상청 / 제조사 보도자료 목록
 → 초안: Claude가 구조화 + ACHAJA 관점 작성 (원문 복제 금지)

 → 검수: 운영자에게 "승인 / 수정 / 폐기" 링크 메일 (Brevo)
 → 게시: KV/D1 저장 → 목록·사이트맵 갱신 → 회원 뉴스레터 대상이면 발송 대기열
```
- 처음 2~3개월은 **사람 승인 필수**. 품질이 안정되면 점검 데이터처럼 위험이 낮은 종류만 자동 게시로 전환한다.
