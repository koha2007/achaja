## 1. 현재 ACHAJA 진단 (2026-10-15 점검 결과 요약)

- 유료 단건 1,900원 / 묶음 5건 7,900원 / 구독 3종(4,900·9,900·29,900원, 오픈 예정)
- **유료 = 무료 + PDF**뿐이며, PDF도 미구현. AI 분석 5섹션(점수·차량 프로파일·리콜 위험도·체크리스트 5개·협상 포인트)은 무료 "베타"로 전부 제공 중.
- AI 입력이 VIN 디코드 + 리콜 매칭뿐 → 같은 모델·연식이면 결과가 거의 같음. 호가·주행거리·번호판은 서버가 받을 수 있지만 페이지가 보내지 않음(`history/index.html:1329`).
- 결제 후 지급 로직 없음. 묶음 7,900원은 서버 허용 금액에 없어 승인 실패(`src/api/payment-confirm.js:6`). 금액 검증이 상품과 연결돼 있지 않음.
- 페이지마다 문구가 충돌함: pricing은 "AI = 유료", history는 "AI 베타 무료", 메타 설명은 "AI 리포트 1,900원".
- 묶음 5건(7,900원)이 Basic 구독(4,900원/월 5회)보다 비쌈 → 가격표가 자기모순.
- 무료 콘텐츠 현황: 뉴스(`/api/news`, 네이버 뉴스 검색 API 요약), 블로그 43편(정적, `scripts/gen-blog-posts.js`로 생성, 마지막 대량 갱신은 2026-05), 리콜 DB 941건.

## 4. 핵심 인사이트 → ACHAJA 설계 원칙

1. **ACHAJA 유료 = "데이터 판매"가 아니라 "구매 결정 패키지"** (CarEdge + RepairPal + CR 모델).
   흩어진 무료 공공 데이터(자동차365·리콜센터·카히스토리 가이드)를 **이 차 한 대 기준으로 묶고, 숫자로 판단해 주고, 현장에서 쓸 도구로 만들어 주는 것**에 돈을 받는다.
2. **무료/유료 경계를 한 문장으로 고정한다.**
   - 무료 = **사실** (VIN 정보, 리콜 건수, 번호판 용도, 종합 점수 + 한 줄 요약)
   - 유료 = **판단과 돈** (적정가 판정, 협상 금액·스크립트, 5년 유지비, 차종별 고질병, 맞춤 현장 점검표 PDF)
   - 모든 페이지에 이 문장을 그대로 쓴다.
3. **유료 리포트에는 반드시 "이 차만의 입력"이 들어가야 한다.** 호가, 주행거리, 번호판, 지역을 받지 않으면 결과가 범용이 되어 돈을 낼 이유가 사라진다.
4. **샘플 리포트 전체를 공개한다** (carVertical·HPI처럼). 결제 전에 무엇을 받는지 정확히 보여 줘야 혼란과 이탈이 줄어든다. `/preview/`에 이미 그 틀이 있음.
5. **보증·환불 장치를 검토한다** (HPI £30,000 보증 → 축소판으로 "리포트 불만족 시 환불"). 1,900원 저가에서도 신뢰 신호가 된다.
6. **가격**: 해외 대비 1,900원은 매우 저렴하다(Carfax의 약 1/30). 가격보다 **가치를 분명하게 보여 주는 것**이 우선이다. 단건/묶음/구독 가격 사다리는 자기모순이 없게 다시 짠다.
7. **자동 콘텐츠는 "재작성"이 아니라 "구조화 + 관점"으로 만든다.**
   2026년 Google scaled content abuse 집행으로, **원문을 AI로 고쳐 쓴 뉴스 사이트는 트래픽이 50~75% 줄었다**. 주 2~3회 자동 게시는 가능하지만, 각 글에는 ACHAJA만의 데이터·비교·체크포인트가 들어가야 한다.
8. **뉴스 저작권**: 원문 복제 금지. 지금의 "네이버 API 요약 + 원문 링크" 원칙을 유지한다.

### ② 뉴스 (무료, 주 2~3회)
- 현재: 네이버 뉴스 API 실시간 목록.
- 개편 방향: **"주간 자동차 브리핑"** 주 2~3회 — 이슈 5개 큐레이션 + 각 이슈에 ACHAJA 한 줄 관점("중고차 사는 사람에게 의미")
- 추가 구성: 리콜 신규 발표 연결, 유가 변동 연결
- 배포: Brevo 뉴스레터(이메일 인프라는 이미 있음)
- 자동화: Cron Worker로 수집 → 초안 생성 → (가능하면 검수) → 게시

### ③ 신차 소개 (무료, 주 2~3회)
- 신차 1대 = 1페이지 고정 템플릿: 가격대, 제원, 연비, 핵심 신기능, 경쟁차 비교표, 출시일
- 출처: 제조사 공식 보도자료, 공공 제원 데이터
- 장기 자산: 이 페이지가 몇 년 뒤 중고차 리포트의 "차량 프로파일" 데이터가 된다(무료 ↔ 유료 연결).

### ④ 점검 데이터 (무료, 주 2~3회)
- 축: 구매 / 정비 / **계절** / **날씨** / **나라별**
- 날씨: 기상청 API → "오늘 날씨 기준 차량 관리 팁"(한파 배터리, 폭우 와이퍼·침수, 폭염 타이어 공기압)
- 유가: 오피넷 무료 API(전국·시도 평균, 전일 대비) → **"오늘의 유가"**
- 나라별: 해외 정비 주기·법규·검사 비교. 영문 토글과 함께 글로벌 SEO 활용
- 기존 블로그 43편을 이 영역으로 흡수해 재분류

### 매일 방문 장치 (벤치마크 기반)
1. **오늘의 유가 + 오늘의 차량 관리 팁**(날씨) — 홈 상단, 매일 바뀜
2. **내 차 등록 → 리콜·정비 시기 알림**(Carfax Car Care 모델) — 이메일 인프라 재사용
3. **주간 브리핑 뉴스레터**(Motor1·The Drive 모델)
