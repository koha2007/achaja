## ★ 결정 (2026-10-15, 사용자 확정)

- **유료 판매 보류.** 대개편은 무료 도구 + 회원가입 중심으로 진행한다. 유료를 포기하는 것이 아니라 판매만 보류한다.
- 유료 수요 검증은 계속한다: 서류 판독을 **회원 전용 무료 베타(월 1~2회)**로 제공하고, 유료 출시 대기자 명단을 받는다.
- 출시 기준(게이트)을 미리 정하고, 넘으면 서류 판독부터 유료로 전환한다. 결제 지급 로직은 그때 구현한다.
- 토스페이먼츠 연동은 삭제하지 않고 비활성화만 한다.
- 이후 설계: `2026-10-15-free-redesign.md` (무료 도구·회원·디자인·사진·가격)

## 1. 판단 기준 — 사용자가 "꼭" 돈을 내는 조건

한국 구매자는 사고이력·시세·리콜을 헤이딜러·자동차365·리콜센터에서 이미 무료로 본다.
따라서 아래 세 조건을 **모두** 만족해야 유료가 성립한다.

1. **이 차 한 대에만 해당하는가** — 같은 모델·연식이면 누구나 같은 결과가 나오는 정보는 검색하면 나온다.
2. **돈이 걸려 있는가** — 결과로 수십만~수백만 원을 아끼거나 잃지 않게 된다.
3. **혼자 하기 어려운가** — 데이터가 흩어져 있거나 해석에 전문 지식이 필요하다.

## 2. 기존 후보 8개 판정

| 협상 금액 + 근거 + 스크립트 | ○ (호가·주행거리 입력 시) | ◎ 직접 절약 | ○ | **핵심** — 돈을 받을 명분 |

## 3. 신규 후보

### ① 매물 서류 판독 — 가장 강력
- 사용자가 **성능상태점검기록부 + 보험이력(카히스토리) 캡처**를 업로드 → AI가 위험 신호 판독
  - 교환·판금 부위 의미(골격 vs 외판), 침수 흔적 표시, 기록부↔보험이력 불일치, 주행거리 이상
- 세 조건을 모두 만족하는 유일한 후보. 사용자가 직접 가져온 자료라 **재배포 문제 없음**.
- 확인 필요: 서류 속 개인정보 처리(미저장·즉시 삭제), 사진 판독 정확도 테스트.

### ② 허위·미끼 매물 경고
- 호가가 시세보다 비정상적으로 낮으면 미끼 매물 패턴 경고 + 자동차365 "실매물 검색" 원클릭 안내.
- 적정가 판정에 붙이면 추가 비용이 거의 없음.

## 4. 추천 구성 — "이 매물 구매 판정 리포트" (MVP)

| 구분 | 내용 | 역할 |
|---|---|---|
| **핵심 1** | 서류 판독: 사고·침수·주행거리 위험 신호 | 손실 방지 |
| **핵심 2** | 적정가 판정 + 허위 매물 경고 | 가격 판단 |
| **핵심 3** | 협상 금액(○○만 원) + 근거 + 협상 스크립트 | 직접 절약 |
| 부록 | 이 차 주행거리 기준 고질병 → 현장 점검표 PDF | 현장 도구 |

- **필수 입력**: 호가, 주행거리, 연식·트림, 차량번호, 지역 / 선택: 서류 사진
- **판매 문장(안)**: "이 매물, 사도 되는지·얼마에 사야 하는지. 수백만 원짜리 실수를 1,900원으로 막습니다."
- 가격: 서류 판독까지 포함하면 가치가 크게 올라감 → 3단계 가격 재설계에서 4,900~9,900원도 검토.

## 5. 데이터 확보 검증 결과 (2026-10-15 조사)

### 5-1. 자동차365 중고차 평균매매가 — **API 없음 (공개 확인 불가)**
- 자동차365 사이트에서 차량번호 입력 → 동일 형식 차량의 최근 1년 등록 건수·평균 매매가·연식별 추세 조회 가능(2021-07 시작). 출처는 **자동차양도증명서 실거래 금액**.
- 한계(공식 안내): 사고 유무·성능·**주행거리**·옵션·색상은 반영 안 됨 → 매물별 적정가로 바로 쓸 수 없음.
- 공공데이터포털·자동차종합정보 개방 서비스 어디에도 **평균매매가 API·파일데이터는 없음**.
- 민간 중개(HYPHEN)가 "중고차매매평균금액 조회" API를 팔지만 **스크래핑 방식**(월 10만 원~) → 약관·법적 리스크, 사이트 구조 변경 시 중단. **채택 비추천**.
- **대응**
  1. 한국교통안전공단 자동차정보처에 평균매매가 데이터 제공 가능 여부 문의 (054-459-7492, 7512).
  2. 그 전까지 적정가는 **"사용자 지원형"**: 리포트 화면에서 자동차365 평균가를 원클릭으로 열고, 사용자가 본 평균가를 입력 → ACHAJA가 주행거리·연식·사고 여부·지역으로 보정해 판정.
  3. 데이터가 끝내 막히면 핵심을 **서류 판독 + 협상(소모품·결함 근거)** 중심으로 옮긴다. 근거 없는 숫자는 팔지 않는다.

### 5-2. 개인 차량 이력을 ACHAJA 안에서 직접 조회할 수 있나 — **대부분 불가**

| 데이터 | 공식 경로 | ACHAJA 안에서 가능? |
|---|---|---|
| 기본정보·제원·검사·정비·성능점검 이력 | 국토부 **자동차종합정보 첨부형 API** (data.go.kr/15071233, 무료) | **사실상 불가** — "소유주의 제3자 정보제공 동의"가 있어야 값을 줌. 동의는 본인인증 + 차량 소유주 확인 필요. 구매자는 소유주가 아님. 신청도 운영단계 심의 + 법인 서류(법인등기부·인감·약정서·안전관리 대책) + 공단 방문 |
| 사업용차량 이력 | 사업용차량 이력정보 API (소유주 미동의 항목) | 렌터카·사업용 차량 일부만. 일반 개인 매물에는 해당 없음 |
| 사고·침수·전손 이력 | 보험개발원 카히스토리 (770~2,200원/건) | **불가** — 국내 기업용 공식 API 공개 안 됨(해외 carVertical·Carseer와만 제휴). 민간 API는 스크래핑 |
| 평균매매가 | 자동차365 화면만 | **불가** (5-1) |
| 실매물(허위매물) 여부 | 자동차365 화면 | 불가 → 링크 안내 |
| VIN 디코드·리콜 | 리콜센터 / 자체 리콜 DB 941건 | **가능** (현재 운영 중) |
| 성능점검 등록 통계 등 집계 데이터 | data.go.kr/15057532 등 (자동승인·무료) | **가능** — 개별 차량이 아닌 통계 |
| 유가·날씨 | 오피넷·기상청 API | **가능** (무료 콘텐츠용) |

### 5-3. 결론 — 3계층 구조

1. **ACHAJA 자동 조회** (API): VIN·리콜·통계·유가·날씨
2. **사용자가 가져오기** (업로드·입력): 성능점검기록부, 카히스토리 결과, 자동차365 평균가, 호가·주행거리 → **유료 리포트의 핵심 재료**
3. **외부 링크 안내**: 카히스토리, 자동차365 통합이력·실매물 조회

→ "ACHAJA가 데이터를 대신 조회해 판다"는 구조는 법적·기술적으로 불가능.
→ "**사용자가 무료/저가로 받은 자료를 ACHAJA가 판독·판정해 준다**"가 현실적이고, 3장 ①(서류 판독)이 핵심이어야 하는 근거가 된다.
→ 판매 문구에 "사고이력 조회", "시세 조회"처럼 데이터를 파는 듯한 표현은 쓰지 않는다(오인·분쟁 방지).
